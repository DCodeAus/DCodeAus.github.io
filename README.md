# DCodeAus.github.io

My personal homepage: **https://dcodeaus.github.io/**

A single static page with no build step or frameworks - it's all in `docs/index.html`, with its styles inline, and it follows your system's light or dark setting.

## How it's published

GitHub Pages serves the `docs/` folder of the default branch. `docs/.nojekyll` tells Pages to serve the file as-is rather than running it through Jekyll. Edit `docs/index.html`, commit and push, and the live page updates within a minute or two.

To preview locally, open `docs/index.html` in a browser.
